# DSA Field Manual

**Data Structures, Algorithms, Analysis & Implementation**

A practical reference for data structures and algorithms, developed alongside **SER 222: Design and Analysis of Data Structures and Algorithms** at Arizona State University.

This repository is intended to turn course material into a long-term engineering reference rather than a collection of assignments that disappears after the semester.

The goal is:

> **Understand it. Implement it. Analyze it. Keep it.**

---

## About

The DSA Field Manual contains my notes, implementations, experiments, and reference material covering the fundamental concepts of data structures and algorithms.

The repository focuses on understanding not only **how** an algorithm or data structure works, but also:

- Why it works
- When to use it
- Time and space complexity
- Design tradeoffs
- Implementation details
- Common mistakes and edge cases
- How to analyze and justify a solution

The material began with **ASU SER 222** and will continue to evolve as I encounter these concepts in later coursework, technical interviews, personal projects, and professional software engineering.
